Role Permission Matrix

      
Read-only reference. Shows what each role can and cannot do across the OnTarget PSP platform.

      

        

          

            Permission
            Admin
            Merchant
            Operator
          

          
        

      

    

    

      

        
Admin

        
Full platform access. Manages merchants, operators, payment methods, analytics, support tickets, and system config.

Auth: X-Admin-Secret header

      

      

        
Merchant

        
Manages their own checkout sessions, can approve/decline payin transactions, view analytics for their own data, and manage webhooks.

Auth: Bearer JWT via /v1/auth/merchant/login

      

      

        
Operator / Depositor

        
Handles payout approvals for linked merchants. Can view payin proof to verify receipts. Operates via the Operator Panel HTML.

Auth: Bearer JWT via /v1/depositors/login
